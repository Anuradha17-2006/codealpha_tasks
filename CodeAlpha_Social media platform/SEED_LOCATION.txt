════════════════════════════════════════════════════════════════
                    HOW TO RUN
════════════════════════════════════════════════════════════════

OPTION 1 (Easiest - Windows):
   1. Double-click: SEED.bat (in connectsphere folder)
   2. Done! ✅

OPTION 2 (Manual - PowerShell):
   1. Open PowerShell in connectsphere folder
   2. Type: cd server
   3. Type: node seed.js
   4. Wait for: ✅ Seeding completed successfully!

OPTION 3 (Manual - Command Prompt):
   1. Open Command Prompt in connectsphere folder
   2. Type: cd server
   3. Type: node seed.js
   4. Done! ✅

                    IMPORTANT NOTES
════════════════════════════════════════════════════════════════

✅ seed.js is in: connectsphere\server\seed.js

✅ You MUST be in server folder to run it:
   WRONG: C:\...\connectsphere> node seed.js
   RIGHT: C:\...\connectsphere\server> node seed.js

✅ Before running seed.js:
   1. Edit .env file with MySQL password
   2. Create database: CREATE DATABASE connectsphere;
   3. npm install (if not done yet)

✅ After seeding:
   1. Run: npm run dev
