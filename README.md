# CodeAlpha Internship Tasks

This repository contains the projects completed as part of my **CodeAlpha Internship**.

## 📂 Projects

### 🌐 Task 2 – ConnectSphere: Social Media Platform

A production-ready social media platform that enables users to connect, share content, and communicate in real time.

**Key Features**

* User Authentication
* User Profiles
* Posts, Likes & Comments
* Follow System
* Real-time Messaging
* Notifications
* Search & Discovery
* Admin Dashboard

**Tech Stack**

* HTML, CSS & JavaScript
* Node.js & Express
* MySQL
* Sequelize ORM
* Socket.IO
* Docker

📁 Project Folder: `CodeAlpha_Social media platform`

---

### 🚀 Task 3 – Projex: Project Management Platform

A modern full-stack project management application built with **React, TypeScript, Node.js, Express, and MySQL**.

**Key Features**

* User Authentication (JWT)
* Project & Team Management
* Kanban Boards
* Task Management
* Role-Based Access Control
* Real-time Notifications
* Responsive UI

**Tech Stack**

* React 19
* TypeScript
* Node.js & Express
* MySQL
* Prisma ORM
* Socket.IO
* Docker

📁 Project Folder: `CodeAlpha_Project management tool`
